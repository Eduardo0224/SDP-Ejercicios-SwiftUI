# SDP2026 Swift Developer Program (Ejercicios) 

Colección de ejercicios desarrollados como parte del programa **Swift Developer Program (SDP)**, enfocados en el aprendizaje y práctica de **SwiftUI**, conceptos modernos de desarrollo iOS y buenas prácticas en arquitectura.

## Descripción

Este proyecto reúne distintos retos y ejemplos prácticos creados durante el proceso formativo del **Swift Developer Program**. Su propósito es reforzar conocimientos en SwiftUI, manejo de estado, navegación, componentes reutilizables, patrones de diseño y mejores prácticas en el ecosistema Apple.

## Requisitos

- macOS 13 o superior  
- Xcode 15 o superior  
- iOS 16 o superior  

## Instalación

1. Clonar el repositorio  
   ```bash
   git clone https://github.com/Eduardo0224/SDP-Ejercicios-SwiftUI.git
   ```

2. Abrir el proyecto en Xcode
    ```bash
    open SDP-Ejercicios-SwiftUI.xcodeproj
    ```

## Ejecución

- Seleccionar un destino (simulador o dispositivo físico).
- Presionar Run o usar atajo ⌘ + R.

## Ayuda

Si experimentas errores comunes:
- Limpiar el proyecto: Shift + ⌘ + K
- Borrar Derived Data si fuera necesario.
