# SwiftUI Heroes App Task – SDP

Tarea 1 del **Swift Developer Program (SDP)** que consiste en implementar un catálogo de superhéroes con navegación maestro-detalle utilizando **SwiftUI** y **Clean Architecture**.

## Objetivo

Desarrollar una aplicación con arquitectura MVVM que muestre un catálogo de superhéroes en formato grid, con funcionalidad de búsqueda, ordenamiento y navegación a una vista de detalle con información completa de cada héroe.
