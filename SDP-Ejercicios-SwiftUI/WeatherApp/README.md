# SwiftUI Weather App Exercise – SDP

Ejercicio 2 del **Swift Developer Program (SDP)** que consiste en emular la interfaz de una pantalla de una app de clima utilizando **SwiftUI**.

## Objetivo

Recrear una pantalla de referencia enfocada en el diseño de una app de clima para practicar el uso de componentes SwiftUI, stacks, tipografías, manejo de imágenes, gradientes, etc...

## Resultado del ejercicio

> - Para la información del `PRONÓSTICO DE HORA` toma la hora actual como primer elemento
> - Para la información de `PREVISIÓN PARA 15 DÍAS` toma el día actual como primer elemento
