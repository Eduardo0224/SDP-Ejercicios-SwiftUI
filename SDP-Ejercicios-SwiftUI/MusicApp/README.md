# SwiftUI Music App Exercise – SDP

Ejercicio 1 del **Swift Developer Program (SDP)** que consiste en emular la interfaz de una pantalla de una app de música utilizando **SwiftUI**.

## Objetivo

Recrear una pantalla de referencia para reforzar el uso de componentes SwiftUI, stacks, tipografías, manejo de imágenes.
